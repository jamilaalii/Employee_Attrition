# Employee Attrition Prediction Using Machine Learning
This project focuses on identifying the factors that contribute to employee attrition within a company and building predictive machine learning models to classify whether an employee is likely to leave the organization. The project uses the HR Comma Dataset to analyze employee-related factors and evaluate the performance of different classification algorithms.Multiple machine learning models were implemented, including Logistic Regression, Decision Tree, Random Forest, and Gradient Boosting. The models were trained, evaluated, and compared using performance metrics to determine the most accurate and reliable approach for predicting employee attrition.The project also explores the effectiveness of combining models to improve prediction accuracy and enhance overall model performance. The final objective was to identify the optimal model capable of delivering the best predictive results for employee attrition analysis.
